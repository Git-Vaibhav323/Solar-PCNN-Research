# Project Context: Solar Power Forecasting using Physics-Constrained Deep Learning

## Overview

This project aims to reproduce and extend a recent research paper on **Physics-Constrained Neural Networks (PCNN)** for photovoltaic (PV) power forecasting. The primary objective is to faithfully reproduce the original methodology using the same datasets, preprocessing strategy, and evaluation metrics before proposing a novel extension that improves model performance, robustness, and physical consistency.

The project follows a research-oriented workflow rather than a typical machine learning pipeline. Every stage should remain modular, reproducible, and well-documented so that the baseline implementation can later be compared with the proposed enhanced model.

---

# Dataset Information

The project uses two primary datasets.

### 1. NSRDB Dataset (Training & Testing)

The National Solar Radiation Database (NSRDB) provides hourly meteorological observations for Chennai, India from **2016–2020**.

This dataset contains all atmospheric variables required for PV power prediction, including:

* Global Horizontal Irradiance (GHI)
* Direct Normal Irradiance (DNI)
* Diffuse Horizontal Irradiance (DHI)
* Temperature
* Relative Humidity
* Pressure
* Wind Speed
* Wind Direction
* Dew Point
* Surface Albedo
* Solar Zenith Angle
* Precipitable Water

This dataset will serve as the primary source for preprocessing, feature engineering, model training, and evaluation.

---

### 2. Renewables.ninja Dataset (External Validation)

Renewables.ninja provides simulated PV power generation using the MERRA-2 weather dataset.

This dataset is **not used for training**.

Instead, it serves as an independent benchmark to validate the generalization capability of the reproduced model, matching the validation strategy used in the original paper.
